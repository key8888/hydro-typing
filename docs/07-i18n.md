# 国際化 (i18n) システム

> ソース: `Hydro/packages/hydrooj/src/lib/i18n.ts`

---

## 1. 概要

HydroOJ の i18n システムは、言語ごとに翻訳マップを保持し、
リクエストに応じて適切な翻訳を選択する。

```
ctx.i18n.load() で翻訳を登録
       ↓
ctx.i18n.translate(str, languages) で翻訳を取得
       ↓
テンプレート内: {{ _('key') }}
ハンドラ内: this.translate('key')
```

---

## 2. 翻訳の登録

### 2.1 基本

```typescript
// applyBlog などの初期化関数内で
ctx.i18n.load('en', {
  blog_main: 'Blog',
  blog_detail: 'Blog Detail',
  blog_edit: 'Edit Blog',
  '{0}\'s blog': "{0}'s blog",
});

ctx.i18n.load('zh', {
  blog_main: '博客',
  blog_detail: '博客详情',
  blog_edit: '编辑博客',
  '{0}\'s blog': '{0} 的博客',
});
```

### 2.2 サポートされている言語コード

| コード | 言語 |
|--------|------|
| `'en'` | 英語 |
| `'zh'` | 中国語 (簡体字) |
| `'zh_TW'` | 中国語 (繁体字) |
| `'ja'` | 日本語 |
| `'kr'` | 韓国語 (ISO コード `ko` ではないので注意) |
| `'fr'` | フランス語 |
| `'vi'` | ベトナム語 |

### 2.3 翻訳の優先順位

複数のプラグインが同じ言語・同じキーを登録した場合、
**後から登録されたものが優先される**。

```typescript
// Plugin A
ctx.i18n.load('en', { greeting: 'Hello from A' });

// Plugin B (後にロード)
ctx.i18n.load('en', { greeting: 'Hello from B' });

// 結果: "Hello from B"
```

---

## 3. 翻訳の取得

### 3.1 テンプレート内

```nunjucks
{{ _('blog_main') }}
{{ _('{0}\'s blog', udoc.uname) }}
{{ _('{0} views', views) }}
```

### 3.2 ハンドラ内

```typescript
const translated = this.translate('blog_main');
const greeting = this.translate('Hello, {0}!', name);
const titled = this.renderTitle('Blog');  // → "Blog - My Hydro Site"
```

### 3.3 言語の解決順序

`this.translate()` が使用する言語の優先順位:

1. **ユーザー設定** `this.user.viewLang`
2. **セッション言語** `this.session.viewLang`
3. **ブラウザの Accept-Language** `this.context.acceptsLanguages()`
4. **システム設定** `system.get('server.language')`
5. **原文そのまま** (フォールバック)

---

## 4. テンプレート内 `{{ _() }}` の動作

`{{ _('key') }}` は以下のように動作する:

1. 現在の言語設定を取得 (上記優先順位)
2. 登録された翻訳マップからキーを検索
3. 見つからない場合は原文をそのまま返す
4. 英語の場合、原文をそのまま返す（英語環境向け最適化）

```typescript
// 翻訳関数の実装 (簡略化)
translate(str: string, languages: string[]) {
  if (languages[0]?.startsWith('en')) {
    // 英語: 翻訳があればそれを使い、なければ原文を返す
    return this.get(str, languages[0]) || this.get(str, 'en') || str;
  }
  // 英語以外: 各言語を順に検索
  for (const lang of languages) {
    const result = this.get(str, lang) || this.get(str, lang.split('_')[0]);
    if (result) return result;
  }
  return str;  // フォールバック
}
```

## 5. i18n キー命名規則

| パターン | 例 | 説明 |
|---------|-----|------|
| 単語 | `'Blog'`, `'Typing'` | 一般的な名詞、メニュー項目 |
| スネークケース | `'blog_main'`, `'blog_detail'` | ルート名やページ名 |
| プレースホルダ | `"Hello, {0}!"` | 数値プレースホルダ |
| フレーズ | `'{0} views'` | 文脈を持つ翻訳 |

**プレースホルダの注意:**
- `{0}`、`{1}` などは数値インデックス
- テンプレート内: `{{ _('{0} views', count) }}`
- 言語によって語順が変わる場合に備えてプレースホルダを使用する

---

## 6. グローバルなロケールデータ

`global.Hydro.locales` に全言語の翻訳が格納される:

```typescript
// 特定の言語の翻訳を取得
global.Hydro.locales.en;
global.Hydro.locales.zh;
```

## 7. 組み込み翻訳キー

HydroOJ 本体が提供する翻訳キー:

```
'Home', 'Blog', 'Typing', 'Problem', 'Contest',
'Discussion', 'Record', 'Ranking', 'Training',
'Login', 'Register', 'Logout', 'Settings',
'Create', 'Edit', 'Delete', 'Save', 'Cancel',
'Search', 'Page', 'of', 'Total',
'Yes', 'No', 'OK',
'Welcome back, {0}.',
'You have {0} new messages.',
```

**注意:** これらのキーは環境によって存在しない場合がある。
カスタムプラグインでは独自のキーを定義することを推奨する。
